# tracer-agent-contract

에이전트 서비스의 계약이다. HTTP 표면, 실행 원장 스키마, 작업 큐와 워크플로 시그니처,
에이전트별 프롬프트 계약과 출력 스키마, 그리고 이것들을 지키는지 검사하는 적합성 스위트를
소유한다.

에이전트 서비스는 구현이 둘이고 TypeScript 구현이 정본이다. Python 구현이 그것을 따라가며
차이가 허용되는 자리는 LangGraph가 강제하는 곳뿐이다. 계약이 별도 저장소인 이유는 언어다.
두 언어가 같은 파일 집합을 읽어야 하는데 어느 구현체 저장소에 두면 다른 쪽이 남의 저장소를
통째로 받게 된다. 두 구현이 이 저장소의 버전을 고정하고 각자의 CI에서 적합성 스위트를 실행한다.

빌드 산출물이 없다. 스펙 파일과 검사기뿐이다.
